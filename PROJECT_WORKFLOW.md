# New project workflow

Start every new website, app, or game in its own GitHub repository under the project’s name. Store the current source, assets, setup notes, and deployment instructions there from the first build. Keep the repository public when the project is meant to be shared publicly and no private material is included.

Build and review the project, publish it from its repository where practical, then add its verified public URL to the right destinations: Salt & Light Web Studio portfolio, Light & Life Games, or a ministry site. Keep the link and preview current as the project evolves.

Give every public launch a distinct 1200 × 630 share image and matching Open Graph and X/Twitter metadata. Check that the image URL loads publicly and that chat previews show the intended title, description, and image. Use the same finished artwork for relevant portfolio cards, and update the hub’s game count from its actual cards.
